岗位页面认证功能测试

功能概述

在首页的"查看岗位"页面中，点击申请岗位、了解详情之类的按键时，系统会自动检查用户是否已登录。如果未登录，会自动跳转到登录/注册界面。

测试功能

点击以下按钮测试认证功能（当前模拟未登录状态）：

实现说明

✓ 所有岗位相关按钮都已添加认证检查

✓ 未登录用户点击按钮会自动跳转到登录/注册页面

✓ 岗位详情查看功能已实现

⚠ 认证检查函数需要根据实际认证机制进行修改

核心代码

// 认证检查函数 function isAuthenticated() { // 检查用户是否已登录 // 这里可以根据实际的认证机制来判断 return false; // 暂时返回false，表示未登录 } // 认证检查包装函数 function checkAuthAndViewJob(jobId) { if (isAuthenticated()) { viewJobDetail(jobId); } else { // 未登录，跳转到登录/注册页面 window.location.href = "{{ url_for('common.auth.sign') }}"; } }

修改的文件

  • 说明文档： LLRC/岗位页面认证功能说明.md

使用方法

  1. 访问 /jobs 路径查看公开岗位页面
  2. 点击任意岗位的"查看详情"或"申请岗位"按钮
  3. 系统会自动检查登录状态并跳转到相应页面
